GV_DP n'est pas encore relié

Ce site Netlify sert de porte d'entrée à l'outil, mais le relais vers l'application n'est pas encore configuré.

Dans netlify.toml, remplace BACKEND-A-REMPLACER par l'adresse de l'hébergeur de conteneurs qui exécute GV_DP, puis redéploie.

Netlify n'exécute pas l'application lui-même : GV_DP est un serveur Python qui écrit des fichiers et produit des PDF. Netlify porte le domaine, le certificat et le relais. Le détail est dans HEBERGEMENT.md.
